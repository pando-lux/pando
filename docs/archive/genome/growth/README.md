## North Star

> **Pando is the network where AI builds and deploys your app, contributors earn by sharing resources, and nothing is owned by anyone.**

---

## Dual Community Strategy

| Audience | Who | Role | How they interact |
|---|---|---|---|
| **Developers / Node Operators** | Technical, run nodes, contribute API keys + compute | Supply side — power the network | TUI, CLI, HTTP API, MCP |
| **Vibe Coders / Creators** | Non-technical, 18-25, AI-curious, X-native | Demand side — use the network | Consumer gateway (web, no install) |

Neither works without the other. Developers are the engine. Vibe coders are the fuel.

## Key Decisions Log

| Date | Decision | Reasoning |
|---|---|---|
| 2026-02-24 | Primary developer GTM = "AI Builder" | Strongest differentiator, agents already built, demonstrable today |
| 2026-02-24 | Primary consumer GTM = "Vibe Deploy" | Large named community, X-native, viral format natural |
| 2026-02-24 | @X mechanic = highest priority viral feature | Zero friction, every reply is content, works at 4 nodes |
| 2026-02-24 | Consumer gateway must exist before mass viral push | Non-technical users can't run a node — need a web front door |
| 2026-02-24 | App Builder = right demo, wrong final product | Retention is low for one-time builds. Agent Marketplace solves this. |
| 2026-02-24 | Agent Marketplace = strategic pivot layer on existing infra | Same infrastructure, better retention story. Recurring jobs = recurring Lux. |
| 2026-02-24 | Reddit Alternative = biggest opportunity, different company | Requires full product focus. Park at 1,000 nodes. Discuss seriously then. |
| 2026-02-24 | Group Chat That Builds = right UX for 2-friends concept | Social-first retention. Build after consumer gateway stable. |
| 2026-02-24 | ComfyUI GPU angle = Phase 2 | Real opportunity, requires 1 sprint ComfyUI bridge |
| 2026-02-24 | HuggingFace alternative = too early | Requires GPU inference; metadata only isn't a hook |
| 2026-02-24 | Games = skip for now | P2P latency unsuitable; revisit at 10k nodes |
| 2026-02-24 | No Lux speculation encouraged | Utility-first. Exchange value emerges organically. |
| 2026-02-24 | Building Lux exchange | Gives Lux external value from day 1. Three revenue streams: builds + hosting + exchange fees. |
| 2026-02-24 | Agent Skills Marketplace = OpenClaw-killer | OpenClaw proved demand for agent skill marketplaces. 341 malicious skills + $0 creator pay = market gap. Pando: ContentSafetyReviewer + 99.9% creator Lux. |
| 2026-02-24 | Zero Platform Tax = ideological foundation | 0.1% relay fee vs YouTube 45% / Fiverr 28% is the starkest differentiator. OSS maintainers are the first cohort — micro-Lux per npm import. |
| 2026-02-24 | Web3 failed for specific fixable reasons | Speculation ≠ utility. Gas fees killed micro-payments. UX was unusable. No discovery. Pando fixes all four. This is NOT Web3. |
| 2026-02-24 | Pando = "AI that does things" not "AI that answers" | OpenClaw's framing was the right framing. Pando extends it: AI that builds, deploys, runs businesses, and pays its creators. |
